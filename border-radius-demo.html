Understanding border-radius: 9999px

Progression of border-radius values:

border-radius: 0 (sharp corners)
border-radius: 4px (slightly rounded)
border-radius: 8px (more rounded)
border-radius: 50% (pill shape with percentage)
border-radius: 9999px (pill shape with large value)
Key Point: When border-radius exceeds half the element's height/width, it creates perfectly rounded ends (pill shape). 9999px guarantees this regardless of dimensions.

Why 9999px instead of 50%?

border-radius: 50%

Works perfectly for pill shapes. Rounds based on element dimensions.

border-radius: 9999px

Also creates pill shape. Uses absolute value that exceeds any dimension.

Visual Breakdown:

Element height: 20px

Half height: 10px

border-radius: 9999px → Browser treats as ~10px on each corner

The circles show how each corner gets a 10px radius (half the height), creating smooth, rounded ends regardless of the 300px width.

Bottom line: border-radius: 9999px is a CSS trick to guarantee pill-shaped elements. The browser caps it at half the smallest dimension, creating perfect rounded ends.
